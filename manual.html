01

SupportDeck 소개

SupportDeck은 자주 사용하는 프로그램, 폴더, 웹사이트, 단축키를 버튼 하나로 실행할 수 있는 윈도우용 단축키 대시보드입니다.

🖱️ 원클릭 실행

버튼 하나로 앱, 폴더, 웹사이트, 단축키를 즉시 실행합니다.

📌 항상 최상단

다른 창 위에 항상 떠 있어 언제든 바로 사용 가능합니다.

🎨 완전한 커스터마이징

버튼 이름, 아이콘, 색상을 자유롭게 변경할 수 있습니다.

⊞ 버튼 그룹

관련 버튼을 그룹으로 묶어 깔끔하게 정리할 수 있습니다.

02

설치 방법

1

설치 파일 실행

SupportDeck_Setup_v1.0.0.exe 파일을 더블클릭하여 실행합니다.

2

설치 옵션 선택

바탕화면 바로가기, 시작 메뉴 등록, Windows 시작 시 자동 실행 여부를 선택합니다.

3

설치 완료

설치가 완료되면 SupportDeck이 자동으로 실행됩니다.

💡설치 시 백신 프로그램이 검사를 진행할 수 있습니다. 검사 완료 후 이상 없음 판정이 나오면 정상적으로 사용 가능합니다.
03

기본 사용법

🖱️ 위젯 조작

위젯 상단 헤더 영역을 드래그하면 화면 어디든 이동할 수 있습니다.

⚙️ 설정
📌 항상 위 고정
— 트레이로 최소화
✕ 종료

👆 버튼 클릭

버튼을 클릭하면 설정된 액션이 실행됩니다.

🖱️ 버튼 우클릭

우클릭하면 편집/삭제 메뉴가 나타납니다. 편집 중인 버튼은 파란 테두리로 표시됩니다.

✋ 버튼 드래그

버튼을 드래그하여 원하는 위치로 이동할 수 있습니다.

➕ 버튼 추가

맨 마지막 + 버튼을 클릭하여 새 버튼을 추가합니다.

💡트레이 아이콘을 더블클릭하면 숨겨진 위젯을 다시 표시할 수 있습니다.
04

버튼 종류 및 액션

+ 버튼을 클릭하면 추가할 버튼 종류를 선택할 수 있습니다.

🔧 커스터마이징

다양한 액션을 설정할 수 있는 기본 버튼입니다. 이미지나 이모지 아이콘, 버튼 색상도 자유롭게 변경 가능합니다.

⊞ 버튼 그룹

여러 버튼을 하나의 그룹으로 묶습니다. 클릭하면 그룹 내 버튼들이 표시되며 ◀ 뒤로가기로 메인으로 돌아옵니다.

⏱️ 타이머

카운트다운 타이머입니다. 클릭하면 시작/일시정지됩니다. 위젯당 1개만 추가 가능합니다.

🔢 카운터

클릭할 때마다 숫자가 1씩 증가하는 카운터입니다. 위젯당 1개만 추가 가능합니다.

05

단축키 버튼 설정

자주 쓰는 키보드 단축키를 버튼으로 만들어 클릭 한 번으로 실행할 수 있습니다.

1

버튼 편집창 열기

버튼 우클릭 → 편집 또는 + → 🔧 커스터마이징으로 새 버튼을 추가합니다.

2

액션 타입 선택

액션 타입 드롭박스에서 ⌨️ 단축키를 선택합니다.

3

단축키 녹화

🎯 눌러서 입력 버튼을 클릭하면 ⏺ 키를 눌러주세요... 상태로 바뀝니다. 이 상태에서 원하는 단축키를 누르면 자동으로 입력됩니다.

06

설정 방법

헤더의 ⚙️ 버튼을 클릭하면 설정 창이 열립니다.

설정 항목설명
테마Dark, Midnight Blue, Forest Green, Crimson, Slate 중 선택합니다. 테마 변경 시 버튼 색상도 자동으로 맞춰집니다.
위젯 배경색위젯의 배경색을 변경합니다. 프리셋 또는 🎨 버튼으로 커스텀 색상을 선택할 수 있습니다.
투명도위젯의 투명도를 40~100% 사이로 조절합니다.
항상 위에 고정체크하면 다른 창 위에 항상 표시됩니다.
작은 버튼 크기버튼 크기를 100px에서 70px로 줄입니다. 아이콘과 이름만 표시됩니다.
Windows 시작 시 자동 실행체크하면 Windows 부팅 시 SupportDeck이 자동으로 실행됩니다.
🔄 설정 초기화위젯 배경색과 버튼 색상을 현재 테마 기본값으로 초기화합니다.
07

Button Layout 백업 / 복원

설정한 버튼 구성을 파일로 저장하고 불러올 수 있습니다. 저장 파일은 앱을 삭제해도 유지됩니다.

📤 내보내기

현재 버튼 구성을 내 문서\SupportDeck\ 폴더에 JSON 파일로 저장합니다.

📥 불러오기

저장된 JSON 파일을 선택하여 버튼 구성을 복원합니다. 저장 버튼을 눌러야 적용됩니다.

💡저장 경로: C:\Users\사용자명\Documents\SupportDeck\layout_날짜시간.json — 다른 PC에서도 같은 버튼 구성을 사용하려면 이 파일을 복사하면 됩니다.
08

자주 묻는 질문

위젯이 화면에서 사라졌어요.
작업 표시줄 오른쪽 트레이 영역에서 SupportDeck 아이콘을 더블클릭하면 다시 표시됩니다.
버튼을 실수로 삭제했어요.
실행 취소 기능은 지원하지 않습니다. Button Layout을 미리 저장해두면 복원할 수 있습니다.
CMD / PowerShell 관리자 권한 실행이 안 돼요.
버튼 편집창에서 관리자 권한으로 실행 체크박스를 활성화하세요.
단축키 버튼이 작동하지 않아요.
지원되지 않는 키 조합일 수 있습니다. 🎯 눌러서 입력 버튼으로 다시 녹화해보세요.
버튼 이름이 한글로 입력이 안 돼요.
편집창이 열린 상태에서 입력란을 클릭 후 한/영 전환 키를 눌러 한글 입력 모드로 변경하세요.
SupportDeck을 완전히 종료하려면?
위젯 상단의 ✕ 버튼을 클릭하거나, 트레이 아이콘 우클릭 → 종료를 선택합니다.
버튼 그룹 안에 또 버튼 그룹을 만들 수 있나요?
현재 버전에서는 버튼 그룹은 1단계까지만 지원합니다.
테마를 바꿨는데 버튼 색이 안 바뀌어요.
설정 창에서 🔄 설정 초기화 버튼을 클릭하면 현재 테마에 맞게 버튼 색상이 초기화됩니다.
